## 1.2.0 - 2026-03-19
* ### Added
* **Job processing modes** - new `mode` parameter in job submission supporting 'base' (full pipeline) and 'lite' (lightweight extraction) options
* **`get_plan_limits()` method** - retrieve plan features and current usage for authenticated organizations on Meta clients
* **`ParsingError` exception** - improved error handling for response validation failures and malformed API responses
* ### Changed
* **Minimum Python version** - now requires Python 3.10 or higher
